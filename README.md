# Homework

这是一个基于 Java 和 Maven 的课程作业项目，用于整理和实现日常练习代码。

## 项目简介

本仓库集中保存课程作业与相关示例，便于学习、运行和复习 Java 基础知识。

## 目录结构

- .想法/：项目构思与记录
- src/main/：主要源代码
- pom.xml：Maven 项目配置文件

## 技术栈

- Java
- Maven

## 运行方式

1. 安装 JDK 8 或更高版本，以及 Maven。
2. 克隆本仓库：

   git clone https://github.com/liping-qu/Homework.git
   cd Homework

3. 使用 Maven 编译项目：

   mvn compile

4. 根据需要运行或调试 src/main/ 下的代码。

## 说明

本项目主要用于学习和课程作业整理，代码会随着学习进度持续更新。
